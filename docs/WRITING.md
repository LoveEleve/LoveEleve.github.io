## 一、快速上手：加一篇新文章

### 文件放哪里

所有内容在 `docs/concurrent/` 下，按主题组织：

```
docs/concurrent/
├── synchronized/
│   └── Synchronized浅析-1/
│       └── Synchronized浅析-1.md    ← 你的文章
└── Java内存模型浅析/
    └── Java内存模型浅析.md
```

### 标题格式

每篇文章用 `# 标题` 开头：

```markdown
# Synchronized 浅析（1）—— 管程、synchronized 与对象监视器

正文从这里开始...
```

### 在首页添加链接

编辑 `docs/README.md`，在对应的 `<details>` 段内加一行：

```markdown
* [Synchronized 浅析（1）](concurrent/synchronized/Synchronized浅析-1/Synchronized浅析-1) — 管程、synchronized 与对象监视器
```

注意：链接不要写 `.md` 后缀，docsify 会自动补全并转成 hash 路由。

## 二、加一个新主题

编辑 `docs/README.md`，在文件末尾（`</details>` 闭合后）加：

```markdown
<details open>
<summary>新主题名称 · N 篇</summary>

**分类名**

* [文章标题](concurrent/新目录/新文件) — 一句话简介

</details>
```

- `open` 属性：新主题默认展开。如果不加 `open`，则默认折叠（用户需要手动点 `▸` 展开）
- 篇数 `N`：改成实际数量，方便读者一目了然

## 三、文章格式规范

### 禁止 AI 痕迹

**不要用** `①②③④⑤` 等带圈数字和 `➊➋➌` 特殊箭头——一眼 AI。

```markdown
# 不要这样
步骤 ① 申请空间，步骤 ② 初始化字段

# 要这样
步骤（1）申请空间，步骤（2）初始化字段
```

### 代码块

```java
public class Demo {
    // 代码块用 ```语言 包裹
}
```

### 引用块

```markdown
> 这是引用块。可以在里面对某个观点做补充说明。
```

### 粗体

```markdown
**这句话会被加粗**
```

如果粗体内含 `[方括号]`，marked 引擎会解析失败。写法：

```markdown
<strong>粗体含[方括号]的内容</strong>
```

### 折线图（ASCII art）

用纯 ASCII `+-|` 画框，不用 Unicode 画线符（`┌┐└┘`），否则对不齐。

```text
+------------------+
|  生产者          |
|  1. 准备数据     |
+------------------+
```

## 四、跨文章引用

**规则：用 `concurrent/` 开头的直写路径，不带 `../` 和 `#/`。**

| ✅ 正确 | ❌ 错误 |
|---------|--------|
| `[AQS](concurrent/AQS/AQS源码解析/AQS源码解析)` | `[AQS](../AQS/xxx.md)` |
| `[JMM](concurrent/Java内存模型浅析/Java内存模型浅析)` | `[JMM](#/concurrent/...)` |

**为什么**：`docsify` 的路由在 URL 的 hash 中（`#/concurrent/...`），`../` 在 hash 里是字面文本，不会向上跳目录。

## 五、边注与注脚

### 行内边注

```markdown
正文内容^[这条注释出现在右侧边距区，带自动编号]
```

### 标准注脚

```markdown
正文引用一个注脚[^1]。

[^1]: 这是注脚定义。注意 `]:` 后必须有空格。续行用 4 空格或 Tab 缩进。
```

### 边注在不同屏幕上的表现

| 宽度 | 效果 |
|------|------|
| ≥1200px | 浮动在正文右侧边距区 |
| 760-1199px | 行内缩进块（左竖线 + 小字灰色） |
| <760px | 隐藏，点编号展开 |

## 六、代码块与图表

### 代码块闭合

每个 ` ``` ` 必须有对应的闭合格，否则后面的正文会被吞进代码块。

```markdown
# ❌ 错误——缺了闭合的 ```
```java
public void foo() {
}
......正文从这里开始被吞进代码块

# ✅ 正确
```java
public void foo() {
}
```
正文正常显示。
```

### ASCII 图表

用纯 ASCII `+-|` 画线，中文算 2 列：

```text
+--------------------------------------+
|  生产者（Publisher）                  |
|  1. 准备数据                          |
|  2. release ----------> 3. 消费者看到 |
+--------------------------------------+
```
